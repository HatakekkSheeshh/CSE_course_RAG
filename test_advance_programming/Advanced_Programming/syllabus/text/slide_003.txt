This course provides essential knowledge about object-oriented model and the level of support for object-oriented model of some popular languages such as C++, Java and ability to create some applications using functional programming language such as Haskell. It helps to understand the main features of object-oriented model through implementing some simple applications as well as functional programming. 4.2.
